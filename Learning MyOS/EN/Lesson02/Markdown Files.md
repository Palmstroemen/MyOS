We think Markdown notes are so easy and useful that we have made them the new base file format of our system.
The old-fashioned ***text.txt*** has served us well since the early days of computers, but it's time to send it into a well-deserved retirement. Say goodbye to ***text.txt*** and other primitive file formats and say hello to ***notes.md***.

Yes, the extension for Markdown notes is ***.md***, as you may have noticed. You might wonder what "md" stands for. We won't solve that riddle here. It's simply a file format like *.jpg, .wav, .pdf* and many others.

For now, you don't need to know more about Markdown files.

Just one more thing: they are not only **easy to write and use**, they are also **very powerful**. You can build an entire project management system on Markdown notes.

There is a very extensive program for working with Markdown notes that you can extend with plugins – into your personal assistant, your customer management system, or whatever you like. It's called [Obsidian](https://www.obsidian.md). And guess what? It's already built in here, right under your feet. You just don't see it yet.

It will appear slowly, bit by bit, as you grow into this system and need more of it. And it stays in the background as long as you don't. That's a core principle of the system you are getting to know here:
**Start small, grow big if needed. Everything is already there when you need it. Everything stays simple as long as it doesn't have to be more complicated.**
