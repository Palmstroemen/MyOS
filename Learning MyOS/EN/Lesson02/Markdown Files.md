We think Markdown notes are so easy and useful that we have decided to make them the new base file format for our system.
The old-fashioned ***text.txt*** served us well since the beginning of modern computers, but it's time to retire it. Say goodbye to ***text.txt*** and other primitive file formats and say hello to ***notes.md***.

Yes, the extension for Markdown notes is ***.md***, as you may have noticed. You might wonder what "md" stands for. It's a file format like *.jpg, .wav, .pdf* ... and others.

For now, you don't need to know much more about Markdown files or notes.

Just one more thing: they are not only **easy to write and use**, they are **very powerful**. You can build an entire project management system based on Markdown notes.

There is a system for working with Markdown notes that you can extend with plugins to become your personal assistant, your customer management system, or whatever you like. It's called [Obsidian](https://www.obsidian.md). And guess what? It's already implemented here, right under your feet. You just don't see it yet.

It will appear slowly, bit by bit, as you grow into this system and need more of it. It will stay in the background when you don't. That's a core principle of the system you're going to experience.
**Start small, grow big if needed. Everything is already there if needed. Everything stays simple and easy if no complexity is required.**

[So let's go on!](<Folders.md>)
