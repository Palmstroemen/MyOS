Let me show you some magic.
For this you need a classic file browser.
You find it in the dock at the bottom of the screen, on the far left. Its symbol looks like a folder.

Open this file browser and navigate to the folder of this lesson: *Learning MyOS/EN/Lesson07*.
There you find a folder called "vacation 2025" full of files.
Have a brief look inside, and leave the folder again so you see it from the outside.

Best place this file browser on the right half of your screen and ours on the left half, so you can see them side by side.

In the left file browser you see the same folder. It might be a small project with just a few files. But as your small project grows, you may want to give it some structure.
A right-click on your folder in the left file browser opens a context menu with: **Turn into a project**.

On the left, the symbol of your folder has changed. It now shows that it has become an "enhanced" project folder.

On the right, the folder hasn't changed at all. This is the "old" file system that doesn't know about our changes. What we do is kind of putting a thin, fancy layer of magic over your operating system. On the left you see the future of computing, on the right the past.
It's a bit like opening the hood of your car: on the right you see the engine, on the left the car with electric windows, seat heating, and all modern comforts.

Now that you know the difference, let's look inside the two folders. Start with the right file browser. It shows what you expect: a bunch of files.

Now look at the left file browser. It looks almost the same, with one difference: **Do you see the standard folders on top?** In the right file browser they don't exist yet. They are only virtually there – pale, as suggestions, unborn folders.

Now, in the left file browser, drag a file into one of these suggested folders. Maybe an invoice into /04_Finance/. **It's a kind of magic!**
All of a sudden, this folder is real. It's not pale anymore. It came to life. Look at the right side! Your new folder is there, with the file inside.
##### Your advantage:
* You didn't have to create a single folder by hand,
* you got a whole set of standard folders for free,
* AND they are always named the same! So your computer understands them even without AI.

Now try to sort all the loose files into your **standard folders**. Leave files that don't fit into any of them outside for the moment.

Maybe a few files are left that don't fit into any of our **standard folders**. But since you are tidying up anyway, you might want to put them into a folder of your own choice. So create one. We don't keep you from creating your own folders and folder structures.

We hope you now understand the principle of our **standard folders**: they are there for you as a suggestion, but they only exist once you actually use them.
