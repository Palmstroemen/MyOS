# Tag exercises

In this lesson there are two small projects: **Apartment renovation** and **Household finances**. Each brings its own tags.

## 1. Find tags and filter
Open *Apartment renovation* in Scope: **[▶ Open Apartment renovation](<myos:open?scope=Apartment renovation>)**. On the right, under **File tags**, you see the tags of the notes: #important, #urgent, #in-progress, #done. Click #urgent: now you only see what is urgent. A second click shows everything again.

## 2. Tag something yourself
Open the note "Balcony ideas" and write #important somewhere in it. Back in Scope: it now shows up under #important. That's how easy a tag in a note is – a word with # in front. Write tags of several words with a hyphen: #in-progress.

## 3. Tag a folder
Open the folder *Bathroom*. On the right, under **This folder**, there is a pale tag without a name. Click it and give the folder a tag. Look at what is suggested: exactly the tags of this project. Choose #in-progress. Right-click the tag to give it a colour.

## 4. Another project, other tags
Now open *Household finances* (**[▶ Open Household finances](<myos:open?scope=Household finances>)**) and give the folder *Receipts 2026* a tag. The suggestions are quite different: #paid, #not-paid, #waiting ... That's how projects keep the flood of tags in check. Then filter by #not-paid: what do you still have to pay?

## 5. Where a project's tags are
A project's tags are in a note: *.MyOS/Tags.md* in the project folder. *.MyOS* is a hidden folder – in Scope you show it with ⚙ → Scope → Hidden folders. Add a line #tax there: from now on it is suggested in this project.
