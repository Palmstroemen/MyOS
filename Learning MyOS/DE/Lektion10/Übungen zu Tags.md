# Übungen zu Tags

In dieser Lektion liegen zwei kleine Projekte: **Wohnungsrenovierung** und **Haushaltsfinanzen**. Jedes bringt seine eigenen Tags mit.

## 1. Tags finden und filtern
Öffne die *Wohnungsrenovierung* in Scope: **[▶ Wohnungsrenovierung öffnen](<myos:open?scope=Wohnungsrenovierung>)**. Rechts unter **Filetags** siehst du die Tags der Notizen: #wichtig, #dringend, #in-Arbeit, #erledigt. Klick auf #dringend: Jetzt siehst du nur noch, was dringend ist. Ein zweiter Klick zeigt wieder alles.

## 2. Selbst taggen
Öffne die Notiz „Ideen für den Balkon" und schreib irgendwo #wichtig hinein. Zurück in Scope: Sie erscheint jetzt unter #wichtig. So einfach ist ein Tag in einer Notiz – ein Wort mit # davor. Tags aus mehreren Wörtern schreibst du mit Bindestrich: #in-Arbeit.

## 3. Einen Ordner taggen
Öffne den Ordner *Bad*. Rechts unter **Dieser Ordner** steht ein blasser Tag ohne Namen. Klick darauf und gib dem Ordner einen Tag. Schau, was dir vorgeschlagen wird: genau die Tags dieses Projekts. Wähle #in-Arbeit. Mit einem Rechtsklick auf den Tag gibst du ihm eine Farbe.

## 4. Anderes Projekt, andere Tags
Öffne jetzt die *Haushaltsfinanzen* (**[▶ Haushaltsfinanzen öffnen](<myos:open?scope=Haushaltsfinanzen>)**) und gib dem Ordner *Belege 2026* einen Tag. Die Vorschläge sind ganz andere: #bezahlt, #nicht-bezahlt, #wartend ... So halten Projekte die Flut an Tags im Zaum. Filtere dann nach #nicht-bezahlt: Was musst du noch bezahlen?

## 5. Wo die Tags eines Projekts stehen
Die Tags eines Projekts stehen in einer Notiz: *.MyOS/Tags.md* im Projektordner. *.MyOS* ist ein versteckter Ordner – in Scope zeigst du ihn mit ⚙ → Scope → Versteckte Ordner. Ergänze dort eine Zeile #Steuer: Ab jetzt wird sie dir in diesem Projekt vorgeschlagen.

---
Noch nicht möglich: beliebige Dateien wie PDFs oder Fotos zu taggen, und Tags mit einer Zahl (zu 40 % erledigt). Daran arbeiten wir.
